# 问题三官方公式核验

直接解析原始 OMML，上下标保留；未修改 Word。

## A 官方明确给出

### budget

来源：`算力约束下提升大语言模型能力的资源配置建模.docx`，`word/document.xml` 第 53 号段落（零起始）。

```text
在算力预算有限时，如何在参数量 N、数据量 D、领域配比 p、数据质量 Q 之间分配资源，并分析当预算水平变化时最优分配是否发生本质改变，是本问的核心问题。上下文长度 L_{ctx} 由模型架构与任务需求外生给定（其可行取值须依据 C7），它通过长文本注意力开销影响可用预算，本问考察其取值对最优配置的影响，而不将其作为内点寻优变量。设总算力预算为 C。为便于对照，建议考察低、中、高三档典型预算：C=10^{19}、10^{22}、10^{24} FLOPs（可自行选取其他档位，但须至少考察三个不同量级的预算）。算力消耗由以下三部分组成。
```

### train

来源：`算力约束下提升大语言模型能力的资源配置建模.docx`，`word/document.xml` 第 54 号段落（零起始）。

```text
基础训练开销：C_{train}=6ND（Chinchilla 近似），其中 N 为参数个数，D 为训练 Token 数。
```

### attention

来源：`算力约束下提升大语言模型能力的资源配置建模.docx`，`word/document.xml` 第 58 号段落（零起始）。

```text
长文本注意力开销：C_{attn}=ηNDL_{ctx}，其中 η=2×10^{-4}，L_{ctx} 为上下文窗口长度（外生给定，取值依据 C7）。上下文长度越大，所需处理的序列位置越多，注意力与缓存等开销越高；本问使用上式作为简化算力代理。
```

### exponential

### power

来源：`算力约束下提升大语言模型能力的资源配置建模.docx`，`word/document.xml` 第 80 号段落（零起始）。

### logarithmic

来源：`算力约束下提升大语言模型能力的资源配置建模.docx`，`word/document.xml` 第 81 号段落（零起始）。

```text
对数渐进型：g(Q)=γln(1+λQ)，其中 γ=2×10^{9}，λ=10.0。
```

## B 解析推导

C_train=C_attn 在 N,D>0 时给出 L_crit=6/eta。CQ 增量在 Q=Q0 为零；三种 g 在 Q∈[Q0,1] 均递增且端点有限。gamma 必须解释为每 token 的 FLOPs 代理，lambda_Q 是无量纲形状参数；它与冻结 lambda_p(N) 不同。

## C 研究者设定

Q0 的聚合/跨域代理映射、主支持域交集、外推域、对数预算网格、经验配方候选集及未来转移判据属于建模选择。架构最大窗口是可行场景依据，不是每次训练真实序列长度；跨架构与 N 的自由组合也是简化代理假设。

## D 旧草稿不继承

未读取旧优化答案。Q0=0.8、质量成本上限 M、旧 N*/D*/Q*、旧转移预算均不继承。eta=2e-4 和三档预算此次由官方 XML 独立恢复，因此可采用；不是沿用旧稿。对数函数不能替换为 -ln(1-Q)；三类函数没有题给总成本上限 M。
